# The menu-bar item

**Date:** 9 October 2026 · **Branches:** `feat/menu-bar-1-icon`, `-2-pause`, `-3-access-setup-delete` (stacked on the first-run PR) · Plan: "Menu bar and project page: build plan", steps 1 to 3

## Problem

LMemM had no icon in the menu bar. The only sign it was running was the pill, there was no way to
quit it except Ctrl-C, and pausing, fixing access, reopening setup and deleting everything were
only reachable from the terminal or by pausing through the pill's card.

## The idea

One small capsule in the menu bar answers one question: is LMemM OK? It wears the pill's single
mark (R8) and the menu under it says the same in words, then lists what you can do.

## Rules (all in `src/menu_model.py`, tested in `tests/test_menu_model.py`)

- **M1** The icon is the pill's capsule. With a mark it wears one badge: red for a permission that is
  off, grey for anything else, two bars in the grey badge for a pause.
- **M2** The top of the menu is the status: a title and one line, the same words as the pill's card.
- **M3** Quit LMemM is always the last row.
- **M4** Pause is a plain row with the pill's three choices, each saying when it ends. Resume replaces
  it when you paused. An automatic pause (you stepped away) has no row.
- **M5** Fixing things is one row each. Check access opens the right pane (or restarts when macOS only
  needs that). Reopen setup and Delete all my data ask once, in words, before they do anything.
  A row that cannot do its job yet is not shown (no "Open project page" until there is one).

## Rows, top to bottom

```
LMemM is watching                 (title, bold)
Every app                         (one line)
─
[Restart LMemM  ─]                only when screen access is on but needs a restart
Add a note                 ⌃⌥N
─
Pause LMemM  ▸  1 hour · Until tomorrow · Until I resume      (or: Resume LMemM)
─
Check access…            [1 off]
Reopen setup…
─
Delete all my data…
Quit LMemM
```

## What each row does

| Row | Does |
|---|---|
| Add a note | Same as ⌃⌥N, including the paused card (R9) |
| Pause / Resume | The pill's own `widget_pause` / `widget_resume` |
| Check access… | Screen off: restart if a new run would be allowed, else System Settings > Screen Recording. Mic off: the Microphone pane. All on: "All access is on" on the pill |
| Restart LMemM | Saves, stops, starts the same command again in place |
| Reopen setup… | Asks, then saves, stops and starts `lmemm.py setup --again`. Memory and notes stay |
| Delete all my data… | Shows how many files and how big, Cancel is the default button. On yes: saves and stops first (`forget.delete_all` refuses while running), deletes LMemM's own data folder, restarts into setup |
| Quit LMemM | Saves and stops, as Ctrl-C does |

## Checked and not checked

Words, marks, row order, "no dead rows", dividers, the pill and menu offering the same pause choices,
and that the tracker answers every row id are tested without a Mac. The drawing (icon, submenu, the
two questions) and the System Settings links are only checked on a Mac.
